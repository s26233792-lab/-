# 配置与冻柠样式

公共默认无账号署名、UTC。`dongning` 是可选个人配置，保留现有创作者风格而不把它变成所有用户的规则。

```sh
cwb --workspace ./private-content init --profile dongning
```

该配置设置 Asia/Taipei、视频 `@冻柠`、卡片 `BY冻柠AI`；视频青绿逐词高亮，黑底电蓝封面与珊瑚橙卡片。工作区可用 `config` 更改非凭证字段。

翻译沿用 DeepSeek 可用且已授权时优先的偏好。服务连接由宿主处理；缺失时根据用户已有授权决定是否使用当前助手，不能虚报 provider。公共中性配置不强制某一家模型。

`youtube_full_review: true` 要求完整转录与上下文审阅，检查视频是否包含批评中国政府或领导人的内容；引用/转述同样记录，纯提及不算命中。命中、疑似或全文无法获得均暂停，等用户明确决定。默认不扩展到 X。工具检查记录与当前转录绑定，不把关键词匹配或模型自动分类当作审阅结论。

公开配置不包含私人账号历史、语气证据、源视频、桌面绝对路径、cookie 或凭证。若用户要自己的 X 声口，使用用户明确授权的样本或私人风格配置；没有样本时不得编造亲历或声称已学会账号声口。
