# 操作与恢复

## 收集后再决定用途

`collect` 只做本地入库。本地文件复制后按内容去重，URL 按来源身份去重。不下载 URL、不转录、不调用语言/图像模型。

用 `list` 查素材，用 `show ID` 查看原文位置及已有稿件，`next ID` 查看未完成工作。需要延期时 `hold ID`；`hold ID --resume` 恢复。

## 一份来源，多个目标

每条素材目录中有 `source/`、`drafts/`、`assets/`、`history/` 和 `builds/`。原始材料与各格式终稿分别保存。视频、卡片、公众号输出各有状态。

处理同一内容的后续请求时，用原 ID，复用有效的原文、转录和证据，不重新收集一个副本。当前版本的输入签名匹配且成品校验通过时，`build` 返回 `cached: true`。

`put` 会保存旧稿历史。文章变化仅使公众号目标失效，字幕变化使视频失效；共同证据、品牌、字体或共享图片变化可能影响多个目标。旧成品仍保存，但无法冒充当前终稿导出。

## 导出

`review` 记录实际检查，`export` 验证当前素材、配置、成品完整性与审校绑定后复制。默认目录形式：

```text
指定导出目录/
  制作日期/
    最终标题（目标）/
      最终标题.mp4 或 最终标题.md
      最终标题.png
      其他配套文件
      package.json
```

再次导出创建新目录，不覆盖旧文件。日期按配置时区。HTML 引用的配图保留稳定相对路径；文件名中不合法字符会替换，原始标题保留在记录里。

素材与导出记录的 `output_title` 同步保存最终发布标题；原平台标题留在 source 元数据里。

`checks.json` 是构建时的机械检查快照；实际后续审校记录位于素材记录和导出包的 `package.json`，两者不混为同一项检查。

## 失败恢复

- 获取失败：检查具体平台错误；可导入同一来源的本地完整文件，不伪造平台支持。
- ASR 中断：同源、同模型设置读取检查点，从未完成区间继续。修改模型或原片新建检查点。
- 渲染失败：保留失败目录和错误，修正后重建；不会缓存不完整成品。
- 超长字幕或卡片：按语义拆分；不要缩到难以阅读。
- 字体缺失：执行 `fonts install`，工具只接受固定校验字体，避免静默系统回退。
- `.lock` 遗留：先确认原任务停止，再移除该文件；不删除任何素材目录。

## 模型服务

工具不内置固定 LLM API。宿主负责研究、翻译、编辑、必要的原声检查与可选图像生成，完成后通过材料文件交接。本地 Whisper 是可选 ASR 实现，也可导入其他经用户授权服务的转录。记录实际 provider，不将本助手输出标成其他模型的结果。
