# 卡片风格库

本页与 `styles/` 中重新制作的模拟样张随技能一起安装。需要卡片或独立封面时读取；只写文稿不询问视觉。七张图使用同一演示主题，说明不同视觉方向，不是七套自动换肤模板。

## 先让用户选

新任务没有指定风格时，用宿主选择组件或一句简短问题展示下表名称，并给出一个有理由的推荐。选项组件放不下七项时，先展示编号与名称，让用户直接回复编号；不要擅自删掉候选。用户要求比较时打开对应参考图。

用户已给编号、名称、别名或新参考图，直接沿用；同一系列、“继续”“和上次一样”不重选。用户明确要求自动选时可以代选并告知；否则等待用户选择后再制作视觉，同时可继续取材与写稿。没有答复不代表接受推荐，不提前生成七套试稿。

## 落实选择

- 把用户实际选择的 `visual_style`（ID）写入本次内容简报；已有 `cards.json` 时也可在顶层记录这个字段，随 `put` 留下修订。它是选择记录，**不是当前渲染器的换肤参数**。不能只写一个 ID 就声称样式已实现。
- 开图前查看所选样张，记录实际制作方法。只借鉴配色、层级、图像处理；替换演示标题、人物、署名和页码，不能把模拟图当作事实来源或真实软件截图。
- 系列保持相同配色、字级与图像处理。换风格时保留已核实文稿与素材；已有同一人物优先复用或编辑，不能为了换背景重新生成另一张脸。
- 小知是编辑讲解角色，保持体型、五官与蓝色蝴蝶结；可以改动作、场景和道具。不得把来源人物经历改成角色亲历，不用伪造的对话气泡冒充原话。
- 语录需核对实际原文与作者；模拟语录为项目自编短句，不能替代本次来源核验。正文密度与张数服从信息量，不为了模板删掉条件或重复凑页。
- 署名取当前用户配置。不把“示例创作者”“内容工作台 / 模拟示例”等演示标识写进正式作品。
- 生成插画用于解释或装饰；原始界面、引文、图表和现场照片使用真实素材。字体遵循技能已核实字体原则；参考图片的字体外观不等于可用字体许可。

## 能力与交付边界

内置 `build ID cards` 仍是深色基础排版：可配置强调色、导入配图，不能自动复刻七种风格。`visual_style` 不会自动改变其布局。基础模板的封面与内页强调色分别配置，选定风格后需要实际检查二者是否一致。

其他视觉由宿主已有的出图、排版和导出能力完成：插画可用无字视觉，再以已核实字体排入本次文稿，逐页检查。把实际提示词、正文与图片保存在同一任务目录；这些独立图片不能冒充已经走过 `cwb build/review/export`，只有真正由工具记录的构建才能按工具导出。

缺少所选风格需要的能力时提前说明，先完成可用文稿；询问用户是否接受基础模板或补齐所需能力，不能擅自降级、把情绪板当成品或宣称自动换肤完成。仅选择风格不授权自动发布。
