# 双语视频制作

先获取完整源视频、原封面和全文转录。个人配置开启 YouTube 门检时，必须先完整审阅并记录；命中或不完整则暂停，详见主技能。

## 材料准备

1. 核对实际讲者和节目，完整读转录；专名、疑似漏句与关键措辞回听，不能用模型自信替代证据。
2. 从真实单词时间分段成中英字幕，中文在上。长句拆成连续短句，不靠缩字号塞满一屏；参考中文单屏约 8–10 个全角字，英文最多两行。所有听清的实质内容都应覆盖。冻柠配置沿用用户对 DeepSeek 的偏好：优先已配置且获授权的连接；不可用时遵守当前会话已有的降级授权，没有授权则先完成独立工作并说明缺口。记录实际执行者，不能把本助手翻译标成 DeepSeek。
3. 只略去无法听清的语气词；在转录相应 segment 标记 `omit: "unclear_filler"` 并记录依据。不要显示“听不清”占位，不把疑似实质漏句当语气词丢弃。保留原声、画面与完整时长。
4. 在 `subtitles.json` 内保留每个词的真实 start/end；可重新分屏，不能平均分配句长。校正转录时同时更新来源记录，不带入旧视频的词修订。
5. 如需要顶部重点词，制作 `keywords.json`：当前原文真实出现的一个词或短语及语境中文义，覆盖对应语义片段；不必每句换词。
6. 准备短封面文字 `cover.json`，有需要时准备三平台 `posts.json`；英文字幕中的人物译文与编辑文案分别保存。

## 固定视觉原则

- 1080×1440 黑底，原片按真实显示比例完整放入中心 1080×608 区域，不裁切、不追踪、不拉伸；保留源片原有文字和标识。
- 16:9 通常为 1080×608，位置 (0,416)。竖屏、方屏和非方形像素先计算显示比例；所有画面完整居中。缩放只做偶数取整。
- 中文 Noto Sans SC 650，ASS 90，亮白，顶部约 y1080；英文静态 700、44，固定末行约 y1252，最多两行。
- 每次只有正在读的英文词变青绿 `#2DD4BF`，其他词为灰色 `#B8BDC3`，读完恢复；真实停顿全灰。整行先排版，逐词只变色，共用基线，不改变换行。
- 顶部标签、英文重点词与中文义按短词/长短语适配。右上角品牌来自配置，冻柠配置只显示 `@冻柠`。
- 无侧栏、时间轴、进度条或时长读数；不加配音和背景音乐。处理源片全部时长。
- 所有新增文字使用固定、已核实的 OFL 字体，生成静态字重/子集时重命名家族并保留许可。源片字体随原画面保留，不声称替源片获得字体授权。

## 制作与检查

```sh
cwb --workspace WORKSPACE put ID transcript transcript.json
cwb --workspace WORKSPACE put ID evidence evidence.json
cwb --workspace WORKSPACE put ID subtitles subtitles.json
cwb --workspace WORKSPACE put ID keywords keywords.json
cwb --workspace WORKSPACE put ID cover cover.json
cwb --workspace WORKSPACE put ID posts posts.json
cwb --workspace WORKSPACE build ID video
```

完整 MP4、中文 SRT、ASS、原封面（实际可得时）、标题封面、代表帧、来源记录和机械检查留在 build 目录。工具比较真实可解码帧数、总时长、音频 PCM、流起点相对偏移，并解码整片。音频复制不兼容或时间原点异常时明确失败，不静默重编码或假称声音一致。

在线视频原封面无法取得时，交付说明必须列出缺项；生成封面不能替代原封面，也不能把缺少配套文件的任务称为全部完成。

查看已编码成片开头、最长字幕、双行英文、当前词切换与结尾。核对讲者、字幕、字体、字重、留白、原画面完整性和听觉同步。机械检查不证明翻译正确或没有漏句。真实检查后登记 `review`，再 `export`。

用户要求指定片段时，当前 v0.1 可导入已经按明确范围准备好的本地片段，并在证据 scope 中记录原时间段；不自动剪精华。原比例/仅中文等额外布局暂未实现，不用默认布局冒充已完成定制。
