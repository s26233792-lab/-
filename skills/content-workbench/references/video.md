# 短视频：翻译、顶部标题与英语跟读

## 先让用户选择

所有模式保留原声、完整画面、全部时长，以及下方中文在上、英文在下的字幕。默认推荐“翻译”，但必须等用户实际选择后再制作。

| 选择 | 顶部黑色留白 | 下方英文 | 所需时间 |
|---|---|---|---|
| 翻译（默认） | 不加标题或重点词 | 普通字幕 | 句子起止时间 |
| 顶部标题 | 显示视频标题 | 普通字幕 | 句子起止时间 |
| 英语跟读 | 重点英文词/短语及语境中文义 | 当前词变青绿，读完恢复灰色 | 真实单词起止时间 |

新任务没有明确选择时，使用宿主的选择组件给出三项；不可用则问：“这个视频用哪种方式？翻译（默认）、顶部标题，还是英语跟读？”默认项不代表已经提交，必须等待用户选择。未回应、关闭组件、只说“开始”，都不能替用户选翻译。

用户明确说“只翻译”“按默认翻译”“顶部加标题”或“英语跟读”已经构成选择，直接记录，不重复询问。续作沿用已记录选择。只有资料收集、获取和必要预检可以在等待期间先进行；翻译、选标题/词条和合成必须等选择明确。

```sh
cwb --workspace WORKSPACE video-options ID
cwb --workspace WORKSPACE video-options ID --mode translation
cwb --workspace WORKSPACE video-options ID --mode title --top-title "访谈｜人物谈具体话题"
cwb --workspace WORKSPACE video-options ID --mode follow
```

`video-options ID` 只返回三项选择、推荐项及是否已记录，不能自动登记选择。`--mode` 记录用户实际选择；用户直接在 CLI 执行该参数也构成明确选择。未记录模式时制作工具会停止，不偷偷采用默认值。不能伪造用户回复。

`--top-title` 指在画面顶部显示的标题，未指定时沿用最终发布标题；它与封面文案分别维护。标题过长时准确精简，不删掉影响事实范围的条件，不伪装成人物原话。署名按个人配置保留。

## 取得与校对完整材料

获取完整源视频、原封面和全文转录。个人配置开启 YouTube 门检时，先完整审阅并记录；命中、疑似或全文不完整则暂停。选择样式和获取素材可以先做，但翻译、生成标题/词条、合成与导出都要等门检通过。

核对实际讲者和节目，完整读转录；专名、疑似漏句与关键措辞回听。忠实翻译，保留实质内容。冻柠配置优先已经配置并获授权的 DeepSeek；不可用时按已有降级授权处理，不虚报 provider。

按自然短句分屏。参考中文每屏约 8–10 个全角字，英文最多两行。长句拆开，不靠缩字号塞字。只有已核实、无法听清的语气词可在转录相应 segment 标记 `omit: "unclear_filler"` 并略去新增字幕；疑似实质漏句需要查清，不显示“听不清”占位。

翻译/顶部标题模式仅需句子时间。平台字幕足够可靠时可直接整理，不强制额外转录或逐词对齐；本地 `transcribe` 在这两个模式下使用句子时间。英语跟读才获取真实词时间，不能平均分配句长，也不能累加不含停顿的 X 词时长。

切换为跟读后保留已核验译文，补充真实词时间和词条；同源 ASR 缓存按是否需要词时间区分。`subtitles.json` 始终含 `start/end/en/zh`，只有跟读必须有 `words`。跟读另需非空 `keywords.json`，每次突出当前原文真实出现的一个词/短语与中文义，不必每句换词；其他模式忽略旧词条文件。

## 画面原则

- 1080×1440 黑底，源片按真实显示比例完整放入中心 1080×608 区域，不裁切、不追踪、不拉伸；保留源片文字与标识。16:9 通常为 1080×608、位置 (0,416)。
- 中文 Noto Sans SC 650、ASS 90、亮白、上沿约 y1080；英文静态 700、44，固定末行约 y1252，最多两行，基线与换行保持稳定。
- 翻译/顶部标题的英文颜色固定为灰色。跟读只有正在读的词变青绿 `#2DD4BF`，真实停顿全灰；整行先排版，逐词只变色。
- 顶部标题最多三行；跟读重点词按短词/长短语适配。品牌来自配置，冻柠配置为右上角 `@冻柠`。
- 无侧栏、时间轴、进度条或时长读数；不加配音、背景音乐。所有新增文字使用固定 OFL 字体，不声称替源片原有字体取得授权。

## 制作、检查与交付

```sh
cwb --workspace WORKSPACE put ID transcript transcript.json
cwb --workspace WORKSPACE put ID evidence evidence.json
cwb --workspace WORKSPACE put ID subtitles subtitles.json
# 用户选择跟读时才需要：
cwb --workspace WORKSPACE put ID keywords keywords.json
# 按需要准备封面与发布文案：
cwb --workspace WORKSPACE put ID cover cover.json
cwb --workspace WORKSPACE put ID posts posts.json
cwb --workspace WORKSPACE build ID video
```

输出完整 MP4、中文 SRT、ASS、可取得的原封面、标题封面、实际编码代表帧、来源和检查记录。构建检查及导出包均记录实际模式。

工具比较真实可解码帧数、完整时长、音频 PCM 与流起点偏移，并解码整片。回到原文检查译文与归属，再查看开头、长字幕、双行英文、顶部标题/词条和结尾；跟读额外检查逐词切换。机械检查不证明翻译正确。

原封面无法取得时如实列出缺项，生成封面不能代替它。真实检查后登记 `review` 再 `export`。模式变化只使视频目标失效，不重做卡片或公众号稿。

指定片段可导入按明确范围准备的本地视频，并在 scope 记录原时间段；不自动剪精华。原比例/仅中文等其他布局暂未实现，不用默认布局冒充定制。
