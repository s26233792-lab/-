# 卡片与封面

先完成来源核验和中文逐页文案，再进入制作。窄事件通常 3 页，普通解读通常 5 页；需要独立解释证据、影响与限制时可 6 页。不重复凑页，不把访谈的关键故事压成没有依据的金句。

每页有独立阅读任务，同时推进整组内容。正文保留必要条件和例子；卡片放不下时调整信息分配，不无限缩字。模板是黑/深灰底、白字、少量强调色，统一页码与可选署名。封面默认电蓝，卡片默认珊瑚橙，均可配置。

`cards.json` 的 `pages` 含 `title`、可选 `label`/`intro`、`blocks`；每个 block 由可选 `label` 和必需 `text` 组成。`layout: "steps"` 使用步骤编号；普通详情用自由块布局。单页可选 `asset` 引用已导入图片名，`image_caption` 给出简短说明；图片完整按比例放入最多 952×320 区域，不拉伸。工具测量真实字体并拒绝溢出，导出 1080×1440 PNG 和整套 `overview.png`。

封面文案放 `cover.json`。未提供图片时使用自绘抽象主题模板，记录为 abstract template。需要具体人物、物件或情境时，使用宿主已有且获授权的图像能力制作无字视觉，或导入有权处理的原封面/同片帧：

```sh
cwb --workspace WORKSPACE asset ID visual.png --name cover-visual
```

`cover.json` 以 `asset: "cover-visual"` 选择它。工具为封面生成灰阶规则网点处理，原图保留不变；字体由确定性排版添加。图片若来自模型，保存真实提示词和生成方式到来源/证据记录，不能把主题插图伪装成原片现场或真实软件截图。

封面可用人物或主题物件；人物取自对应素材而非上传者头像，保持身份。不得复制参考截图的界面、商标、水印或其他人物。不伪造 logos、基准图表或可读软件界面。

制作后查看每张图片的中文、标点、数字、页序、署名、人物身份和手机缩略图可读性。默认封面 3:4。公众号封面由公众号目标单独制作，不拉伸竖版封面。
