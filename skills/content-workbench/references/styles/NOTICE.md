# 模拟样张说明

本目录七张 PNG 于 2026-11-06 重新制作并同步为冻柠自媒体 Skill 的名称，统一使用“把收藏变成作品”的演示主题，替换此前展示的历史参考。每张 1080×1440、3:4。它们用于比较视觉方向，不是七套内置自动换肤模板，也不是实际来源、名人引语或平台截图。

| 文件 | 本次制作 |
|---|---|
| `dark-blue.png` | 新生成虚构创作者插画，灰阶网点、电蓝重点与新写文案 |
| `warm-collage.png` | 新生成纸张、书本和手册拼贴，暖白黑橙排版 |
| `comic-explainer.png` | 参考原小知角色特征，重新生成整理笔记场景并排入三步说明 |
| `dark-orange.png` | 新生成网点笔记本插画，黑底橙色分区排版 |
| `minimal-white.png` | 白底极简 HTML 排版，项目新写的三段说明，无外部配图 |
| `quote-pencil.png` | 新生成铅笔淡彩场景，短句由项目自编，明确标为非人物引语 |
| `social-post.png` | 浅色阅读卡 HTML 排版，虚构示例作者与文字头像，无平台标志、认证或互动数据 |

五种插画由内置 `image_gen` 生成；全部中文以 Noto Sans SC / Noto Serif SC（字体内嵌许可为 SIL OFL 1.1）另行排版，经浏览器导出，未把模型生成字形当作已授权字体。没有分发字体二进制，也没有在 PNG 中嵌入字体文件。

代码、项目新写文案和排版适用仓库 MIT 许可；项目作者在其可授权范围内按同一许可提供本次模拟样张。生成插画不构成对真实人物、事实、独占性或商标权的声明。新作品使用本次实际来源与用户署名，不照搬示例标识。

完整制作提示词、字体指纹和首页图解记录保存在仓库的 `docs/images/simulated-samples.md`。安装后的技能只依赖本目录样张与相邻风格说明，无需私人文件。
